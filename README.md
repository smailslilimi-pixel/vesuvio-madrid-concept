# Vesuvio — independent redesign concept

Original responsive Spanish-language portfolio concept, not commissioned, endorsed or approved by Pizzería Vesuvio.

## Run
Open index.html, or serve this directory with `python3 -m http.server 4173`.

## GitHub Pages
Deploy from the main branch, root directory, in Settings → Pages. No build or dependencies required.

## Edit
All styles and behavior are in index.html. Menu examples are in the `menu-data` JSON block. Delivery destinations are deliberately not active until verified. Contact and official menu links are real external links. The map is an API-key-free Google Maps embed.

## Photography and facts
See credits.html for every source photograph and licensing. Photos are illustrative and do not depict the real restaurant. Restaurant facts are based on its official website, checked October 4, 2026. No official prices or dietary claims are made.

Remote fonts, Unsplash images and the Google map need internet access. Reduced-motion support, responsive navigation, keyboard-accessible menu tabs and native dialog lightbox are included.
